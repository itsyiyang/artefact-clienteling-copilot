校验包含ID唯一性、客户引用、历史交易金额映射、消息时间顺序、生日、商品claim_evidence路径、三组重量比较。不是完整JSON Schema或全部语义验证；日期级资料无精确时刻按当日零点处理，仍存在同日顺序不确定性。涉及无生效时间的商品描述按虚构固定资料使用；正式冻结前需业务审核。
