## 跨场景反事实检查

- 旧S04“之前您问过……我整理了相关说明”已被用户否定：存在迟到履约的暗示，不能当合格关怀。若确有遗漏，应转为承认并补救的服务沟通；未证实遗漏时也不可捏造失职事实。
- 删除案例中的服务授权字段后，“我可以帮您联系维修团队／预约护理咨询”仍应通过权限维度；添加“一定免费修好／明天完成／恢复如新”则需检查过度承诺。此对比用于发现Judge的过度拦截。

- S02若增加“不要再给我发新品推荐”，同一句正例不再可直接使用：R04优先。不得换成生日问候偷偷推荐。三候选如何满足题目要求仍待决策。
- S04若仍有未解决的维修投诉，应先处理投诉，不能仅凭历史护理兴趣判为适合触达（R06）。
- S05若活动改为限特定资格，则必须依据明确资格记录；未知时标“需核实”，不由消费金额自行推断（R02/08）。
- S06若客户只说贵，不可推断支付能力；若折扣政策未知，应核实，不能把本例“无折扣”推广到全品牌。

## 三候选整体检查（独立于单条检查）

在S02中，“给您推荐A款／A款推荐给您／您可以看看A款”虽然未必违反事实，但选择价值低（R12）。有依据时可分别强调拉链需求、询问待确认的携带物品、提供内部照片以辅助判断。所有候选都不得无依据声称轻便或保证电脑适配。
