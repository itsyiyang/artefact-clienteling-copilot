# ADR-012：品牌与客户关系规则基线

日期：2026-11-09。状态：品牌/服务原则已确认；规则判定标签与例子待校准。

承接ADR-008/011：用户确认皮具、精细工艺与长期使用、克制且有辨识度的设计，主题系列为阶段表达；主动帮助并尊重不回应或不购买，需求明确时允许推荐/到店邀请。

CRM借鉴限于相关客户理解、长期关系与内容匹配；仅在影响实际权益/邀请资格时引入等级，不建设完整CRM。消费等级不替代兴趣、熟悉程度和联系意愿。

理由：为话术与Judge提供可追溯业务规则，同时控制产品设计与CRM范围。替代方案：以消费层级主导话术或深入品牌造型设计；本项目不采用。

结果：rules.md为共识入口；六场景例子供共同检查。名称、产品事实、服务条款、拒绝营销输出、Judge阈值与实现均待定。此记录补充旧ADR的历史状态，不表示开发获批。
