# ADR-013 — Workflow质量门、有限修正与独立评估

日期：2026-11-09。状态：讨论共识已确认，待实现；不代表当前Demo已具备以下行为。

## 决策

1. 优先级：独立策略规划 → 差异化检查 → 小样对比与用户校准 → 扩大评测；网页美化最后。
2. 理解客户、场景、商品/活动与原话约束后，独立规划三个方向，再生成对应候选。方向随情境变化，不固定套用三个模板。每个方向说明客户价值、事实依据和沟通动作；不可为求差异编造事实或越过边界。
3. Judge同时检查单条质量与三候选整体。单条合规不能抵消整体雷同；方向不同的标题也不能代替正文的实际差异。
4. 正常路径：理解 → 独立规划 → 生成 → 自动Judge → 不通过则内部定向修正和复评 → 整组通过后展示给CA。失败草稿、策略、判断、版本和修订链内部留存，供bad-case分析。
5. 修订按问题范围决定：措辞只改相关条目；重复时重新规划受影响方向；共同误解时回到理解/规划。无论改几条，都复评最终整组。
6. 有限重试，不无限生成或逐轮降低门槛。沿用讨论参数：最多两轮内部自动修正；CA辅助修改另算、首版一次。这些次数是可调整的首版参数，不是题目规定。
7. 最新用户修正：重试耗尽仍未通过时，允许展示未通过结果。作为明确标注的例外展示，附未通过原因、问题片段和待核实事项；不得标成已通过或计入正常通过率。默认解释为供CA审核的草稿，不自动发送；具体是否禁用复制/选择仍待讨论。
8. 重试失败展示不等于绕过明确拒绝。若当前不应触达或没有有效候选，展示原因和补充信息/调整目标路径，不强行凑三条；正式题目三输出契约仍待决定。
9. CA对正常候选可选择、收藏、喜欢/不喜欢、提出修改方向、一键重新生成。选择表示本次采用意向；收藏表示留作参考；偏好反馈不等同于质量真值。新一组或CA修改后的内容仍需检查。交互与反馈持久化待实现。
10. Judge属于运行时质量检查；evaluation为独立系统评估，不另串一个Evaluation Agent。固定案例 → 不同方案 → 原始结果/Judge/修订链 → 人工标注 → 汇总比较。对比直接生成、独立策略生成、策略+Judge+修订；保留首次及修订后成绩、重试次数、耗时、失败率、误判/漏判与人工分歧。同模型自评分变高不证明真实改善。

## 当前实现差距

现有本地Qwen3:8b Demo把理解/规划/生成合在一次调用；Judge及一次Edit由按钮触发；尚未实现独立规划、自动质量门、有限自动修正、收藏/反馈持久化或完整对照评估。已有真实产品推荐小样不能代表六场景或正式50例验证完成。

## 待定

通过阈值与评分锚点；受限场景的合理差异标准；失败例外区的选择/复制行为；重生成历史和反馈字段；拒绝营销与正式三输出要求的处理。
