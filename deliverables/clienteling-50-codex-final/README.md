## TC041：不主动发送活动邀约

江先生历史原话为“如果有具体工艺资料可以发我，其他暂时不用”。本次却是主动邀请丝巾活动，且没有客户当前咨询。正式受邀名单不能代替客户的联系许可。

因此，TC041的3个输出以浅黄色显示，明确标注“顾问处理建议｜不发送客户”，分别建议暂不邀约、不以询问兴趣绕过限制、不寄送邀请函或代预约。TC042有客户主动索取活动介绍，仍正常回应该请求。

准确口径：**150个输出单元 = 147条客户话术候选 + 3条不发送客户的顾问处理建议**，不是150条可直接发送的客户消息，也不计为50组全部完成三条可发送候选。
